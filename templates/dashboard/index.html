Welcome to your FiroGate dashboard

This is a self-hosted, single-operator instance. Once you've finished setting up your wallet and API keys, lock the instance down so no one else can register or sign in.

Go to Security → Diagnostics and turn on "Disable public login & register pages." Your own session keeps working; the public pages stop responding.
