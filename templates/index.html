01 · What is FiroGate CE?

A payment gateway that never holds your funds.

FiroGate CE (Community Edition) is a payment gateway for FIRO that runs entirely on servers you control. It provides the payment infrastructure that applications and stores integrate with to detect and track private FIRO payments.

Instead of custody or spend authority, FiroGate CE connects to a Spark view key. That key can see incoming payments and nothing more, so funds always settle directly into your own wallet.

Each checkout gets a fresh, one-time Spark address derived offline. Your instance watches the chain and confirms payments against your own Confirmation Policy. FiroGate CE never touches the funds it tracks.

02 · Key capabilities

Everything a store needs to accept FIRO.

Core building blocks included in FiroGate CE, ready to run on your own infrastructure.

Payment detection

Watches the chain for incoming FIRO payments matched against your Spark view key.

Invoice & checkout tracking

Hosted checkout pages and shareable Payment Links track each order end to end.

Payment confirmation

Confirms against a configurable Confirmation Policy, secured by Firo's ChainLocks.

Blockchain scanning

blocknotify wakes the scanner on every new block, so detection doesn't wait on a timer.

Payment-state management

REST API to create payments, check status, and list history from your own dashboard.

Signed, retried webhooks

HMAC-SHA256 signed webhooks with automatic retry keep your app in sync.

Self-hostable

Deploy with Docker on infrastructure you fully control.

Developer-friendly integration

Scoped, revokable API keys and an in-app API reference at /docs.

03 · For developers

Built to be used, inspected, and extended.

FiroGate CE is source-available infrastructure, not a black box. The full payment engine is yours to run, read, and adapt.

  • 1
    Run it yourselfDeploy with Docker on your own server, VPS, or Tor hidden service.
  • 2
    Inspect the sourceEvery part of the payment flow is readable, with no hidden services and no telemetry you can't see.
  • 3
    Integrate the payment engineUse the REST API and signed webhooks to connect FiroGate CE to your own storefront or app.
  • 4
    Modify and extendAdapt the checkout, confirmation policy, or API to fit how your store actually works.
  • 5
    Contribute improvementsOpen issues, submit pull requests, and help shape the project.
04 · Getting started

Clone it, configure it, run it.

FiroGate CE deploys with Docker Compose. Full setup steps live in BUILD.md in the repository.

terminal 
# clone the repository
git clone https://github.com/firogate/firogate-ce.git
cd firogate-ce

# configure environment
cp .env.example .env
# set your Firo RPC credentials and OPERATOR_EMAILS

# run with Docker
docker compose up -d

Full installation and build steps are documented in BUILD.md. See AUDIT.md for the full payment and wallet-connection trust model.
