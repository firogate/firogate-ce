Platform Features

Built for production

Every feature is designed around real merchant needs — not demos.

Real-time via SSE

Checkout pages update instantly when payment arrives — no polling, no refresh. Server-Sent Events push updates directly to the browser.

HD Wallet addresses

Each order gets a unique derived address. No address reuse, complete on-chain privacy, and full tracking per payment.

Webhook delivery

HMAC-SHA256 signed payloads delivered to your server on every event. Verify signatures, retry on failure, full delivery logs.

Automatic withdrawals

Request a withdrawal from your dashboard or via API. Funds move from the gateway wallet to your personal address on-chain.

Payment Links

Create shareable payment links with no API required. Ideal for social sellers, invoices, and one-off transactions.

Tor & clearnet

Runs on both clearnet and Tor hidden services simultaneously. Same integration, same checkout — full privacy stack for privacy-first merchants.

Security Architecture

Designed to be trusted

Self-hosted

You run the server. You control the wallet keys and the infrastructure. No third party between you and your funds.

API keys hashed

Raw API keys are never stored. Only SHA-256 hashes. Shown once on creation — like Stripe, GitHub, and Cloudflare.

Webhook signatures

Every webhook is signed with HMAC-SHA256. Verify on your server — reject anything unsigned.

HMAC checkout tokens

Every checkout URL includes an HMAC token. Even a guessed payment UUID is useless without it.

Rate limiting

Per-IP rate limiting on all endpoints. SSE connections capped. Abuse automatically throttled.

Self-hosted

Run on your own server. Your data, your infrastructure. No third-party access to your keys or transactions.
